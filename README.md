# Task Manager REST API

A small Spring Boot REST API for creating and managing tasks. The project demonstrates a typical controller-service-repository structure with Spring Web, Spring Data JPA, and an H2 database.

## Features

- Create, read, update, and delete tasks
- Spring Boot REST endpoints
- Spring Data JPA persistence
- H2 in-memory database for local development
- Maven Wrapper included for reproducible builds
- Docker support

## Tech Stack

- Java 17
- Spring Boot 3.5
- Spring Web
- Spring Data JPA
- H2 Database
- Maven

## Project Structure

The Spring Boot application lives in the `taskmanager/` directory.

```text
TaskManager-Spring-Boot/
├── README.md

    ├── pom.xml

    ├── Dockerfile

```

## Run Locally

### Prerequisites

- Java 17 or newer

Clone the repository and enter the application directory:

```bash
git clone https://github.com/knoxdevchris/TaskManager-Spring-Boot.git
cd TaskManager-Spring-Boot/taskmanager
```

Run the application with the Maven Wrapper:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
mvnw.cmd spring-boot:run
```

The API will be available at `http://localhost:8080`.

## API Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| GET | `/tasks` | Get all tasks |
| GET | `/tasks/{id}` | Get one task by ID |
| POST | `/tasks` | Create a task |
| PUT | `/tasks/{id}` | Update a task |
| DELETE | `/tasks/{id}` | Delete a task |

### Example Task

```json
{
  "title": "Study Spring Boot",
  "description": "Review controllers, services, and repositories",
  "dueDate": "2026-08-30"
}
```

The `id` is generated by the application.

### Example Request

```bash
curl -X POST http://localhost:8080/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Study Spring Boot","description":"Review REST APIs","dueDate":"2026-08-30"}'
```

## Tests

From the `taskmanager/` directory:

```bash
./mvnw test
```

## Docker

Build the image from the repository root:

```bash
docker build -t taskmanager-api ./taskmanager
```

Run it:

```bash
docker run --rm -p 8080:8080 taskmanager-api
```

Then call the API at `http://localhost:8080/tasks`.
